## 17. Responsive behavior

Desktop can be dense and multi-pane. Mobile should prioritize court attendance, task completion, document/photo upload, client contact, expense capture, time tracking, matter summary, notifications and quick court outcome capture. Administration builders may be desktop-optimized but must still be viewable on tablet and provide safe read-only mobile fallbacks where editing complex diagrams is impractical.
