# Media and insights

Content types: article, video, press release, podcast and downloadable guide. Each publication owns slug, title, excerpt, body blocks, author, practice areas, topics, cover/media assets, SEO, social artwork, publish schedule and revision history.

Video should use asynchronous thumbnail/transcode jobs in the existing worker queue. Public playback never auto-starts audible media. Article pages use a ~760px reading measure and connect back to relevant partners/practice areas.
