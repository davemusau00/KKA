# SEO, performance and accessibility

## SEO
Per page: title, meta description, canonical, OG metadata, robots, breadcrumbs and JSON-LD. Use appropriate Organization/LegalService/Attorney/Article/VideoObject/FAQ schemas.

## Rendering
Prefer publish-time pre-render/static output for CMS pages. Dynamic API hydration is reserved for search, forms and truly live information.

## Targets
LCP <2.5s, CLS <0.1, INP <200ms. Serve AVIF/WebP responsive images, lazy-load below-fold media, prefetch likely navigation.

## Accessibility
Target WCAG 2.2 AA: semantic headings/landmarks, skip link, visible focus, 44px touch targets, labelled forms, useful error text, keyboard menus/carousels, reduced motion and sufficient color contrast.
